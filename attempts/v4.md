# Attempt v4 — native 8×8 SVD, atlas B, sparse leftover

Branch: `attempt/v4` off `attempt/v4.t4r`.  
Frozen: v0–v4r under `public/media/v*/` (and `media/v*/` on the GitHub tree).  
This branch **rewrites** the live reconstruct and the lab — it is the product encode, not a probe.

Raster: **640×360** crop, canvas 640×384, 24 fps, 15 flux shots (same as t2r–t4r).  
Tile **8×8**, TRAIN_STEPS=2, K_MAX=16, target 32.5 dB.  
Atlas JPEG-on-B q=70 (one mosaic per shot). Leftover JPEG q=40, stride 8, MAE>3.5.

## Kill criterion (written before encode)

t4r already picked the stack. v4 has to **ship it**: native reconstruct, origin file, lab default = v4.

Quality: mean reconstruct PSNR vs the 640×360 source must clear **32.5 dB**.  
Size: origin must come in **under t4r A** (32.5 MB int8). H.264 is 6.8 MB; beating that is not the knife.

**Survived.** Full 90s **33.95 dB** (min 28.05, median 33.88). Origin **15.23 MB zlib** (raw 23.77). Encode 192 s.

## Reading (after the numbers)

**Atlas is the size lever, U is what is left.** Origin 15.23 MB = atlas 1.98 + leftover 0.86 + μ JPEG 0.47 + zlib(int8 U). t4r 8×8 int8 was 32.5 MB / 35.76 dB. Atlas JPEG-on-B cut B from thousands of tiles to one mosaic per shot and dropped the origin ~2×. The remaining ~20 MB of raw U barely zlib-compresses — same lesson as v4r.

**The atlas tax is ~2 dB vs int8 B.** Time-weighted SVD-only (K=16 ladder) sits ~1.8 dB under t4r A on the same shots (S09 35.18 vs 37.31, S06 31.48 vs 33.80). t4r J (per-tile JPEG-B) was 34.36 dB / 16.6 MB. v4 is 33.95 / 15.23 with leftover mixed in — same neighbourhood, one JPEG per shot instead of 3840.

**Sparse leftover did not buy the tracking hole.** Stride 8, MAE>3.5, q=40: 135 frames, 0.86 MB. Per-shot lift is +0.15 to +0.27 dB (S06 31.48 → 31.75). t4r’s dense leftover on S06 was +3.17 dB / +1.30 MB. The product leftover is a meter, not a quality stack. S06 min 30.19 and S13 min 30.16 still sit under the 32.5 knife on those frames.

**K′ still works as a decode peel.** Episode SVD-only: K′=0 20.8, 1 29.2, 2 31.8, 4 33.1, 16 33.8. Full reconstruct 33.95 includes leftover. K′=8 prints 34.1 because S07 (T=235) and S14 (T=459) only stored 0/4/16 — that mean is not episode-wide. Do not read 8 > 16 as a rank inversion.

**Native vs v4r is not a dB contest.** v4r was 34.68 dB on 320×180 (12.09 MB). v4 is 33.95 dB on 4× the pixels (15.23 MB, 2.14× the 6.8 MB H.264 source). The 32.5 knife is vs the 640×360 original, which is the point of this encode.

**What is still the next honest branch:** (1) **compress U** (the blob that did not move); (2) leftover that is actually dense on tracking shots, or a second cheap pass, if min-PSNR matters; (3) real MC (predict current, residual in current coords) — naive warp-then-SVD is dead. Nested 8→16→32 trees, 2×2-up merge, episode shared B stay backlog.

## What it is

| Lever | v4r | v4 |
|---|---|---|
| Raster | 320×180 | **640×360** |
| Tile | 16×16 | **8×8** |
| Spatial bases | int8 B per tile | **one JPEG atlas of B per shot, q=70** |
| Temporal | int8 U + 2-step ALS | same |
| Residual | none | **sparse leftover JPEG q=40 / stride 8** |
| Decode knob | K′ | **K′** (rank peel, not a spatial pyramid) |
| Syntax | NAR4 v1 zlib(int8 U,B + JPEG μ) | **NAR4 v2** zlib(μ JPEG + atlas + mn/sp + int8 U + leftover) |

RDO per 8×8: smallest K such that remaining MSE ≤ 36.6 (32.5 dB), cap K=16. K=0 stores nothing but the shot-mean JPEG.

Self-test: `still_k=0`, `fade_k=1 fade_mae=0.000`, `atlas_mae=0.002`.

## Origin syntax

`NAR4` + version `2` + zlib of:

- header: W, H, fps, n, nshot, patch, atlasQ, leftoverQ
- per shot: `[i0,i1)`, μ JPEG, atlas JPEG, float32 mn/sp, uint8 K per tile, int8 U + float32 scales for K>0, leftover `(t, jpeg)*`

No warp. No MV. Decode paints `μ + U[:, :K′] @ B_atlas`, then adds leftover on those frames.

## What it still is not

A 15 MB origin that beats H.264. A shared spatial decoder. Dense leftover on tracking. Motion compensation. A rank-16 subspace that covers a rotating head — S06/S13 still miss 32.5 on the worst frames, and spending K further is the 40 dB / 14.7 MB t4r Q path, not this encode.
