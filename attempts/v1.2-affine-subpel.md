# Attempt v1.2 — shot-level affine + sub-pel

Branch: `attempt/v1.2-affine-subpel`  
Frozen v0: `attempt/v0-global-translation`  
Frozen v1 (broken warp): `attempt/v1-block-mc`  
Frozen v1.1 (closed integer MC): `attempt/v1.1-mc-correct`

Same 16×16 skip / residual / intra stack as v1.1. No nets. No CU tree. The leftover that v1.1 could not eat was geometric: push-ins, mild pans, and any field the hard 3×3 median flattened.

## Kill criterion (written before encode)

If residual+intra bytes drop by less than ~15% vs v1.1 (2,816,300 B → still above 2,393,855 B) **and** tracking leftover still looks like a ghosted object, stop. That leftover is appearance, then go to nets. 16×16 nets cannot implement a dolly; putting them on v1.1 residuals would spend capacity relearning six affine numbers.

**Survived on bytes.** Residual+intra 2.69 MB → 1.94 MB (−28%). Origin 3.39 MB → 2.60 MB. Tracking smear is the remaining visual question, not a byte fail.

## What changed

| Lever | v1.1 | v1.2 |
|---|---|---|
| Global warp | one translation (half-pel) | 6-param sampling affine (scale / rotate / shear / translate) |
| Local MVs | hierarchical integer ±8 then ±2 | integer, then half-pel 3×3, then quarter diamond |
| Median | hard 3×3 | snap only if dist > 2.5 **and** MAD < 0.85 |
| Warp sample | integer block copy | bilinear per-block, edge-pad never 0 |
| Motion bytes | skip bitmap + 2 B × coded blocks | + 24 B affine per predicted frame |

Convention is unchanged: `pred[x] = ref[x − dx]`. Affine `A` maps current → ref. Content scale `s > 1` is a camera push-in. Small-res affine scales to full-res by multiplying the translation coefficients by 4.

Affine search: translation + half-pel first; a scale/rot grid `{0.96…1.04} × {−2°…+2°}` only wins if MAE is 0.03 better; a 4×4 ±3 translational grid lstsq affine only wins if MAE is 0.05 better.

Self-test: `tx=4.0 warp_mae=0.000`, `local_mae=0.008`, `halfpel_mae=0.000`, `zoom_scale=1.040 zoom_mae=1.100`. Adaptive median snaps a spike at [3,3] and keeps a radial field.

Affine actually fired: 91 frames with `|s−1| > 0.005`, 137 with `|rot| > 0.2°`. Mean scale 1.0001, mean |rot| 0.055° — most of BBB is still a translation. The byte win is skip: the affine + sub-pel pred clears `SKIP_MAE=2.6` more often, so residual/intra atlases shrink. Mean leftover and PSNR moved the other way (~0.8 dB) because those extra skips are a little dirtier than v1.1's residual-coded blocks. That is RDO, not a broken loop. Min PSNR 27.0 dB is still nowhere near v1's 10.6 dB black-tile collapse.

## What it still is not

A rotating head, a new aspect, two-depth parallax that disagrees inside one 16×16, grain. Those are appearance. Residual nets are the next branch — this raster is the geometric baseline they should sit on, not v1.1.
