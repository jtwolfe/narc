# Attempt v1.1 — motion loop, actually closed

Branch: `attempt/v1.1-mc-correct`  
Frozen v0: `attempt/v0-global-translation`  
Frozen v1 (broken warp): `attempt/v1-block-mc`

Same 16×16 skip / residual / intra stack as v1. No nets. The loop is honest.

## What v1 was actually doing

Search scored `prev[x+dx] ≈ cur[x]`. Warp sampled `prev[x-dx]`. Local search and `warp_blocks_rgb` had the same inversion. Prediction was shifted by ~`2·MV`. Out-of-frame blocks were written as literal `0`. Mode decision never saw those zeros because MAE came from an edge-padded search. Residual JPEG then tried to paint a translated picture at q=52.

That is why v1 looked blocky and jumpy, why pans grew a black strip, and why the origin was 5.4 MB of leftover.

## What changed

| Lever | v1 | v1.1 |
|---|---|---|
| MV sign | search ≠ warp | `pred[x] = ref[x − dx]` everywhere |
| OOB | write 0 | edge-pad; holes → intra |
| Modes | search MAE | MAE of the buffer that lands in recon |
| Height | 180 = 11×16 + 4 orphan px | pad to 192, crop to 180 |
| Residual | full-frame JPEG, skip=128 | packed atlas of residual blocks only |
| Intra | raw source copy, 48 B fiction | JPEG atlas of intra blocks |
| Local MV | ±2 around a backwards global | hierarchical ±8 then ±2, 3×3 median |
| Loop filter | none | 1-px deblock on disagreeing edges |

Self-test (synthetic +4 px): warp MAE 0.000 vs identity 8.9. v1's warp on the same pair was *worse* than doing nothing.

The origin shrank *and* PSNR went up. That is the signal that prediction is finally doing work. Min PSNR moving from 10.6 dB to 28.5 dB is the pan/swarm shots no longer collapsing into black tiles.

`blackTileFrames` in stats is a mean<12 count; on this clip it flags dark forest interior, not coded zeros. The v1 failure frames (30.3s swarm, 61.3s tracking) have **zero** 16×16 tiles at mean 0.

## What it still is not

Tracking / parallax / push-ins still smear — local translation cannot express a camera dolly or a rotating head. Residual JPEG of leftover texture is still the bulk of the origin (1.7 MB). Intra atlas is another 1.1 MB. 90% skip is skip of a 16×16 *translation*, not of an affine.
