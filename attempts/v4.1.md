# Attempt v4.1 — selectable K′ decode + leftover toggle

Branch: `attempt/v4.1` off `attempt/v4`.  
Frozen: v0–v4 under `public/media/v*/`. This branch does **not** re-encode.
It unpacks the v4 NAR4 v2 origin and peels rank at decode. Origin leftover
(JPEG residual vs full rank, stride 8) is an independent decode switch.

## Kill criterion

K′ must be a real decode switch in the lab, not a printed ladder. Origin
bytes must not change. Leftover JPEG stays off the peeled rungs — it was
computed against full K.

**Survived, then extended.** Same 15.23 MB origin. Leftover is now a lab
toggle on every peel: the origin residual is applied after `μ + U[:, :K′] @ B`,
which is what a decoder with both knobs actually does. It does **not**
recompute leftover against the peel — so μ + leftover is still μ with a
tiny grain on leftover keys, not a quality stack.

## What it is

Decode `μ + U[:, :K′] @ B_atlas`, then optionally add leftover JPEGs.
The lab bakes both families so the player can switch without a JS decoder.
`[` `]` peels rank. `L` toggles leftover. Origin is a copy of v4’s
`origin.nar4`.

Self-test: S00 f0 PSNR 31.82 matches v4’s stored frame; K′=0 is the shot mean.

## Best method

**Dense leftover JPEG, stride 1, MAE>3.5, q=40.** That is the moving-element
fix. Affine / warp-then-SVD is not (t4r −5.7 to −14 dB). Decode deblock is
not (seamR 1.30→1.28). v4’s stride-8 leftover is a meter: S06 min stays 30.19.

Stride must be 1. S06 s2 min 30.29 vs SVD 30.19 — the worst frames are the
ones a skip hits. s1-all == s1 on S06 (every frame already above the 3.5 MAE
knife). Tile leftover is worse than full-frame leftover (JPEG-on-8×8 mosaics
are header-bound), same lesson as per-tile JPEG-B.

**Overlap is the lattice path, not the motion path.** Hop-4 Hann COLA on 8×8
drops S06 seamR 1.64→1.08 and S09 1.30→1.07, at 15 105 tiles vs 3840 (~4×)
and 13.5 MB zlib on S06 alone. Stills: leftover restores the butterfly;
overlap softens the grass grid and leaves the insect faceted. Ship leftover
first. Add hop-4 only if the remaining 8×8 on locked skies is still the demo
complaint.

The lab leftover toggle is the **origin** leftover (s8), so you can see what
the bitstream actually stores at every K′. Packing stride-1 leftover would
be a new encode, not this decode demo.

Crops: [`attempts/v4.1/crops/`](v4.1/crops/) — S06 t=80 (tracking) and S09
t=100 (locked), src / svd / leftover-s1 / deblock / overlap.

## What this pass is

K′ peel of the frozen v4 origin, then a leftover on/off bake of that same
origin residual on every peel. Blockiness campaign as above. Lab default is
K′=full, leftover on (the v4 reconstruct).

Not a re-encode. Not dense leftover in the origin. Not overlap in the origin.

## What it still is not

A bitrate knob. A JS origin decoder. Dense leftover packed into NAR4.
Overlap. Real MC.
